EXIT ZONE 개발 일지 - 2024년 12월 7일
===========================================

[ 오늘 작업 내용 ]

1. 프로젝트 초기 설정
   - Godot 4.5 프로젝트 생성
   - 폴더 구조 생성 (scenes, scripts, resources, assets)
   - project.godot 설정 (입력 매핑, 오토로드, 물리 레이어)

2. 오토로드 스크립트
   - GameState.gd: 게임 상태 관리, 씬 전환
   - InventoryManager.gd: 인벤토리, 스태시 관리

3. 플레이어 시스템
   - player.gd / player.tscn
   - 이동 (WASD), 마우스 조준, 사격 (LMB)
   - 재장전 (R), 상호작용 (F), 회복 (Q)

4. 무기 시스템
   - WeaponData 리소스 클래스
   - 3종 무기 리소스 생성:
     * P1 Sidearm (권총)
     * SMG-Alpha
     * AR-15 Ranger
   - Projectile (탄환) 구현

5. 적 시스템
   - Scav AI 구현 (scav.gd / scav.tscn)
   - 상태: 패트롤 → 추격 → 공격
   - 기본형 / 강화형 구분

6. 루팅 시스템
   - LootBox (상자) 구현
   - ExtractionZone (추출 지점) 구현 - F키 2초 홀드

7. 씬 구성
   - menu.tscn: 메인 메뉴
   - field_raid.tscn: 1단계 필드 레이드 (사막)
   - defense_raid.tscn: 2단계 디펜스 레이드 (던전)
   - result_screen.tscn: 결과 화면

8. HUD/UI
   - HP바, 탄약 표시, 붕대 개수
   - 추출 진행바, 웨이브 표시

9. Kenney 에셋 적용
   - Desert Shooter Pack (필드 레이드)
   - Tiny Dungeon (디펜스 레이드)
   - 플레이어, 적, 무기, 탄환, 상자에 텍스처 적용
   - 타일셋 리소스 생성 (desert_tileset.tres, dungeon_tileset.tres)

10. 필드 레이드 맵 디자인 시작
    - TileMapLayer로 타일 페인팅 진행 중

11. MVP 시스템 대규모 업데이트 ★
    - 기지 시스템 추가 (base.tscn)
      * 퀘스트 패널 (quest_panel.gd)
      * 제작 패널 (craft_panel.gd)
      * 스태시 패널 (stash_panel.gd)
      * 로드아웃 패널 (loadout_panel.gd)
    - 플레이어 스테미나/스프린트/회피 시스템
      * Shift - 스프린트
      * Space - 회피 (무적 프레임)
    - 필드 레이드 시간제한 + 시련(TRIAL) 시스템
      * 3분 제한시간
      * 시간 초과 시 TRIAL 페이즈 시작 (강화 적 스폰)
    - 레벨/경험치/저장 시스템
      * JSON 기반 세이브/로드
      * 레벨업 시 제작법 해금
    - 재료 드롭 및 제작 시스템
      * 재료: scrap_metal, gun_parts, cloth, chemicals
      * 무기/소모품 제작
    - HUD 업데이트 (타이머, 시련 경고, 레벨/XP 표시)
    - 맵 생성기를 에디터 기반 타일 페인팅으로 전환
